AMRL Website Editor

How this editor works: (open it any time by adding #edit to the website address) Change the fields below and click Preview changes. To make changes public on GitHub Pages, click Download updated index.html, then replace the old index.html in your GitHub repository and commit it. This static website cannot publish directly to GitHub without a secure GitHub sign-in/token.
Tip: Photo fields accept an image URL or a relative path such as photos/your-photo.jpg. Upload the image file to the same GitHub repository. Use the exact filename and capitalization.
